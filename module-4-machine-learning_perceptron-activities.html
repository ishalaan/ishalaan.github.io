Activity Brief

This activity explores the implementation of simple and multi-layer perceptrons using Python in Jupyter Notebook. It involves watching the unit lecturecast and running three programmes in sequence, beginning with a simple perceptron, applying a perceptron to the AND operator and examining a multi-layer perceptron using the sigmoid activation function.

The completed Python activities, programme outputs, observations and explanations of perceptron behaviour are documented in this section of the e-Portfolio, followed by a reflection on the findings and limitations of these neural network models.

The activity addresses the following learning outcomes.

  • Understand the applicability and challenges associated with different datasets for the use of machine learning algorithms.
Simple Perceptron

The model applies a weighted sum followed by a binary threshold. With input vector x = [45, 25] and weights w = [0.7, 0.1], the score is 45 × 0.7 + 25 × 0.1 = 34. The output is 1 when the score is at least 1, and 0 otherwise. This is equivalent to a zero-threshold unit with a fixed bias of −1.

Configuration Score Output
Reference weights [0.7, 0.1] 34 1
First weight changed to −0.7 −29 0
Inputs scaled to [0.45, 0.25] 0.34 0
Inputs [1, 0] 0.7 0
Inputs [0, 10]: exactly on threshold 1 1
Reference inputs; threshold raised to 35 34 0
Decision Behaviour

Reversing the first weight changes the score from 34 to −29 and switches the output. The threshold is inclusive, so an observation exactly on the boundary belongs to class 1. For the original weights, the boundary is 0.7x₁ + 0.1x₂ = 1. Changing the weights changes the boundary; changing the threshold shifts it.

The score is not a probability. This example contains no training loop, target labels or weight estimation, so it demonstrates inference rather than learning. The input-scaling comparison also shows that numerical units matter: scaling the inputs without adjusting the weights or threshold can change the classification. The dot product offers a compact implementation, but no runtime comparison was conducted.

Perceptron AND Operator

The AND model uses the four binary input combinations with targets [0, 0, 0, 1]. Weights start at [0, 0], the learning rate is 0.1 and the activation threshold is 1. The reference update increases weights when the output differs from its target. Under this configuration it reaches weights [0.5, 0.5] after five update passes; a sixth pass confirms zero mistakes.

Inputs Target Final score Prediction
[0, 0] 0 0 0
[0, 1] 0 0.5 0
[1, 0] 0 0.5 0
[1, 1] 1 1 1
Learning Rule and Sensitivity

AND is linearly separable: 0.5x₁ + 0.5x₂ ≥ 1 selects only [1, 1]. However, the reference rule uses abs(target − prediction), so weights cannot decrease after a false positive. The comparison implementation uses the signed rule w ← w + η(target − prediction)x and caps every run at 100 passes.

Configuration Passes Final weights Truth-table accuracy
Reference rule; initial [0, 0] 6 [0.5, 0.5] 100%
Reference rule; initial [1.25, 1.25] 100 [11.25, 11.25] 50%
Signed rule; initial [1.25, 1.25] 4 [0.95, 0.95] 100%
Signed rule; rate 0.05, initial [0, 0] 12 [0.55, 0.55] 100%
Signed rule; rate 0.2, initial [0, 0] 4 [0.6, 0.6] 100%

The high-initial-weight case exposes the defect: the reference rule continues increasing both weights and reaches the iteration limit without converging. Signed updates correct the false positives. Pass counts include the final zero-error pass where convergence occurs; floating-point arithmetic can affect threshold comparisons near 1.

All four possible binary inputs are used in training and evaluation. The result verifies the AND truth table; it is not a held-out accuracy estimate. A fixed threshold also restricts which boundaries can be learned, so convergence in these examples should not be generalised to arbitrary datasets.

Multi-Layer Perceptron

The network models XOR using two input units, three hidden sigmoid units and one sigmoid output. Its targets are [0, 1, 1, 0] for inputs [0, 0], [0, 1], [1, 0], [1, 1]. Unlike AND, XOR cannot be separated by a single straight decision boundary. The hidden layer introduces a nonlinear representation.

The activation is sigmoid(z) = 1 / (1 + exp(−z)), with derivative s(1 − s) when s = sigmoid(z). At zero, the output is 0.5 and the derivative is 0.25. Large positive or negative inputs approach saturation, where small derivatives can slow weight updates. The architecture contains no trainable biases, matching the reference model.

Training and Results

The reproducible baseline uses random seed 1, weights initialised between −1 and 1, learning rate 0.6 and 400,000 full-batch updates. Backpropagation uses the transposed output-weight matrix and computes both layer deltas before updating either matrix. The inconsistent weight variable name in the reference implementation is corrected. Predictions are recomputed after the final update and classified using a threshold of 0.5.

Inputs XOR target Sigmoid output Prediction
[0, 0] 0 0.008195 0
[0, 1] 1 0.993546 1
[1, 0] 1 0.993547 1
[1, 1] 0 0.008977 0

Final mean absolute error is 0.007520, with all four truth-table outputs correctly classified. The optimiser follows the gradient of half the summed squared error; MAE is a separate reporting measure. Subtracting MAE from 1 does not calculate classification accuracy, and sigmoid outputs are not assumed to be calibrated probabilities.

Learning Rate and Initialisation

The following comparisons each use 20,000 epochs. Learning-rate runs share seed 1, while seed 7 isolates an initialisation change at rate 0.6. These shorter runs are separate from the 400,000-epoch baseline.

Learning rate Seed MAE Truth-table accuracy
0.1 1 0.164687 75%
0.6 1 0.138456 75%
2.0 1 0.031816 100%
0.6 7 0.040840 100%

The results show that optimisation depends on both step size and starting weights. Rate 2.0 reaches the correct classifications sooner in this comparison, but that does not establish a generally optimal rate or guarantee stability on other problems. The notebook plots error against actual epoch numbers. Perfect agreement on this four-row domain demonstrates XOR behaviour rather than generalisation to noisy real-world data.

Reflection

The three analyses separate inference, learning and representation. The fixed-weight unit applies a decision rule; the AND model adjusts a linear boundary; the hidden-layer network learns a nonlinear mapping. The AND sensitivity test is particularly important because a successful baseline can conceal an incorrect update rule. A signed correction is essential when false positives require weights to decrease, consistent with the error-driven learning principle underlying perceptrons (Rosenblatt, 1958).

Backpropagation distributes the output error through the hidden layer using the chain rule (Rumelhart, Hinton and Williams, 1986). In the XOR implementation, consistent matrix dimensions, update ordering and a fixed random seed are necessary for interpretable comparisons. The learning-rate and initialisation results also show why an epoch count alone is not evidence of convergence. Reporting the optimisation objective, MAE and thresholded accuracy separately avoids confusing different measures of performance.

A hidden layer expands representational capacity, but capacity is not a guarantee of successful training. Cybenko (1989) establishes approximation properties for sufficiently flexible sigmoidal networks; this does not guarantee convergence of a particular three-unit network without biases. The Boolean datasets cover only four inputs and contain no noise or sampling uncertainty. More realistic applications would require appropriate scaling, representative data, independent evaluation and checks on sensitivity to initialisation before making performance claims.
