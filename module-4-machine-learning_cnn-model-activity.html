Activity Brief

This activity explores the implementation and evaluation of a Convolutional Neural Network (CNN) for object recognition using Python in Jupyter Notebook. It involves reviewing the different sections of the provided CNN model, examining its architecture and performance, and changing the selected test image from index 16 to an index between 1 and 15 to observe whether the model predicts the correct class.

The activity also involves reading Wall (2019) and considering the ethical and social implications of CNN technology. The model implementation, evaluation results, image prediction experiments, ethical considerations and reflection will be documented in this section of the e-Portfolio, providing a basis for discussion during the subsequent unit seminar.

The activity addresses the following learning outcomes.

  • Articulate the legal, social, ethical and professional issues faced by machine learning professionals.
  • Understand the applicability and challenges associated with different datasets for the use of machine learning algorithms.
Dataset & Preprocessing

CIFAR-10 contains 60,000 colour images measuring 32 × 32 pixels across ten object classes: airplane, automobile, bird, cat, deer, dog, frog, horse, ship and truck. The official split contains 50,000 training images and 10,000 test images. Each test class contains 1,000 images. The data are retrieved through the Keras CIFAR-10 loader; the dataset documentation describes their composition and origin.

Partition Images Role
Training 40,000 Parameter updates
Validation 10,000 Early-stopping decisions
Test 10,000 Final evaluation

The first 10,000 records of the official training set form the validation set; the remaining 40,000 are used for training. This preserves the reference split and is not a stratified sampling procedure. Images are converted to float32 and divided by 255, mapping channel values to [0, 1]. Labels are encoded as ten-element categorical vectors. Image tensors retain shape (n, 32, 32, 3); flattening occurs inside the network after convolution and pooling.

No augmentation or per-channel standardisation is applied. The low resolution and restricted class vocabulary make this a useful benchmark, but they do not represent the range of lighting, backgrounds, camera quality or unfamiliar objects encountered in deployment. The first training image is labelled frog; the reference notebook's automobile caption is corrected in the analysis.

CNN Architecture & Training

Two convolution–pooling blocks extract spatial features before a dense classifier assigns one of ten labels. Each convolution uses 32 filters, a 4 × 4 kernel, stride one, valid padding and ReLU activation. Each max-pooling layer uses a 2 × 2 window. Shared convolutional weights reduce the number of parameters compared with connecting every input pixel directly to every hidden unit (LeCun et al., 1998).

Training uses Adam with learning rate 0.001, categorical cross-entropy, batches of 32 and a maximum of 25 epochs. Early stopping monitors validation loss with patience two. As in the reference implementation, restore_best_weights=False: evaluation uses the final epoch's weights, not automatically the weights with the lowest validation loss. No dropout, augmentation or weight regularisation is introduced.

The fresh run completed 7 epochs. Its lowest validation loss was 1.0770 at epoch 5. TensorFlow 2.20.0 and Keras 3.15.1 were used. Python and TensorFlow seeds were set to 112 and the NumPy seed to 888. Modern Keras imports and an explicit input layer replace obsolete API calls; float32 reduces memory use. Library and numerical differences mean this run is not expected to reproduce the historical weights exactly.

Model Evaluation

The test set is evaluated after training, without using test labels to choose the stopping epoch. Accuracy measures the proportion of correct top-one predictions; cross-entropy also reflects the probability assigned to the correct class. The supplied notebook's saved outputs are retained as a historical reference and are distinguished from the fresh run below.

Run Test accuracy Test cross-entropy Epochs
Supplied notebook (saved outputs) 67.03% 1.0768 9
Fresh execution 63.04% 1.1195 7

Final training accuracy was 72.40%, compared with validation accuracy of 63.70%. Validation loss reached 1.0770 at epoch five, then increased to 1.1177 by epoch seven while training loss fell from 0.9409 to 0.7956. This divergence is consistent with overfitting: fitting the training data more closely no longer improved validation cross-entropy. Stopping after two non-improving epochs limits further fitting but does not itself restore the best model or establish robust generalisation.

The highest class recall was for truck (74.7%) and the lowest for dog (38.6%). The largest directed confusion was dog predicted as cat, affecting 355 images. The notebook includes the full confusion matrix, with actual classes in rows and predicted classes in columns. These patterns identify errors for closer inspection; they do not establish why a particular feature caused a prediction.

All classes have equal test support, so macro-average recall equals overall accuracy here. A single seeded run does not measure variability across initialisations. Evaluation on this benchmark also provides no evidence about unfamiliar classes, image corruption or demographic fairness. Further model selection should use validation data and repeated runs before a final test evaluation.

Image Prediction

The prediction check compares index 16 with every alternative index from 1 to 15 in the test set. A single index variable selects both the displayed image and the model input, preventing an image from being presented alongside a prediction made for a different record. The class is obtained with argmax(model.predict(x_test[index:index+1]), axis=1), replacing the removed predict_classes method.

The fresh model classified 12 of the 15 alternative images correctly. The notebook displays all sixteen selected images with their actual and predicted classes. Index 16 was correctly identified as dog. The alternative-image errors were ship predicted as truck (index 2), frog as deer (index 4), and ship as frog (index 15). These examples were selected by index rather than by outcome; they illustrate individual decisions but are too few to estimate general performance. The full test-set result provides the stronger assessment.

A softmax score is a model output, not a verified probability that a prediction is correct. No calibration analysis is performed here. A high score can accompany an error, and this closed-set classifier always selects a known class even when an input may not belong to any of them.

Ethical & Social Implications

Wall (2019) describes concerns about false facial matches, unequal performance and surveillance without meaningful public consent. The consequences of an error depend on its use: confusing two animal images in a benchmark differs substantially from wrongly identifying a person as a suspect. The article is a historical account of the debate in 2019, rather than a statement of current law or current system accuracy.

The CNN analysed here classifies objects; it does not identify people. Its differences in class recall cannot establish demographic bias in facial recognition. Wall also discusses research on gender classification, which is distinct from identity matching. A responsible assessment must define the actual task, affected population and consequences of both false positives and false negatives before choosing performance measures.

Class balance alone does not ensure representative data. Collection conditions, labelling practices and intended uses should be documented, including restrictions on reuse (Gebru et al., 2021). Where people are involved, an assessment should examine privacy, meaningful consent, data minimisation and the possibility that surveillance discourages lawful participation. Better accuracy would not by itself resolve those concerns.

Responsibility extends across development and deployment. Raji et al. (2020) propose auditing throughout the system lifecycle; practical safeguards include documented decisions, assessment of affected groups, review of failures and a clear route to challenge harmful outcomes. Human review must have the information and authority to reject an automated recommendation. Some proposed uses may remain inappropriate even after technical improvements. Reflection

This analysis shows the value of examining the complete prediction pipeline. Correct image selection, consistent preprocessing and an explicit stopping policy are essential to interpreting the result. Convolutional feature learning provides a compact spatial model (LeCun et al., 1998), but the class-level errors demonstrate how much an aggregate accuracy figure can conceal. A useful next comparison would evaluate restored-best weights and augmentation under a fixed validation protocol, with several seeds to assess variability.

The ethical lesson is that benchmark performance is only one part of judging a system's suitability. Wall's (2019) examples show how recognition errors can become consequential when attached to surveillance or policing. Dataset documentation (Gebru et al., 2021) and lifecycle auditing (Raji et al., 2020) offer concrete ways to examine assumptions, intended uses and responsibility. The CIFAR-10 results support a bounded claim about object classification; they provide no basis for approving identification systems used on people.
