Activity Brief

This activity explores communication between intelligent software agents using Knowledge Query and Manipulation Language (KQML) and Knowledge Interchange Format (KIF). The task involves constructing a structured dialogue between two agents, Alice and Bob, within a warehouse procurement scenario. Alice is responsible for procuring stock, while Bob manages warehouse inventory and provides information about product availability and specifications. The dialogue demonstrates how agents can exchange information through standardised communication messages and formal knowledge representations.

The scenario requires Alice to obtain two pieces of information from Bob to support procurement decisions. The dialogue must address the following requirements.

  1. Determine the number of 50-inch televisions currently available in the warehouse.
  2. Identify the number of HDMI ports available on those televisions.

The interaction consists of four messages, with Alice initiating each request and Bob providing the corresponding response. KQML is used to define the communicative purpose of each message, while KIF represents the information exchanged in a formal, machine-interpretable structure. The completed dialogue is documented in this e-Portfolio, supported by an explanation of the design approach, a critical evaluation of the communication method and a reflection on the learning achieved.

The activity addresses the following university learning outcomes.

  • Understand the motivations for, and appropriate use of, agent-based computing.
  • Understand the main agent models in use today and their grounding in artificial intelligence research.
Design & Approach

The dialogue is designed as a simple information exchange between two autonomous software agents operating within a warehouse procurement environment. Alice represents the procurement function and requires accurate inventory information to support purchasing decisions, while Bob represents the warehouse management function and maintains knowledge of product availability and technical specifications. The agents have distinct responsibilities but must communicate effectively to achieve the shared objective of informing procurement activity. Rather than accessing Bob's internal inventory records directly, Alice submits structured queries and relies on Bob to interpret them and return the requested information.

The communication design combines Knowledge Query and Manipulation Language (KQML) with Knowledge Interchange Format (KIF). KQML provides the outer communication structure and specifies the intention behind each message through performatives. The ask-one performative is selected for Alice's requests because each question seeks a single value, while tell is used for Bob's responses because it communicates information held by the warehouse agent. KQML message parameters identify the sender, receiver, content language and message content, enabling the interaction to be interpreted consistently. KIF provides the representation of the information contained within these messages through logical predicates, variables and expressions. This separation distinguishes the communicative act from the knowledge being communicated.

The agents and their responsibilities are defined as follows.

  • Alice acts as the procurement agent, initiating requests for inventory quantities and product specifications.
  • Bob acts as the warehouse agent, responding to queries using information maintained in the inventory knowledge base.
  • KQML specifies the purpose and routing of each communication message.
  • KIF expresses the requested inventory facts and corresponding responses in a structured logical form.

The dialogue follows a sequential request-response pattern consisting of four messages. Alice first queries the quantity of available 50-inch televisions, and Bob responds with the relevant stock figure. Alice then requests the number of HDMI ports associated with the televisions, and Bob returns the corresponding specification. The KIF expressions use agreed predicates to represent stock quantities and product attributes. Variables allow Alice to request unknown values, while Bob's responses substitute those variables with specific information. The design assumes that both agents share the meaning of the predicates and refer to the same television product category.

  1. Alice sends an ask-one message requesting the available quantity of 50-inch televisions.
  2. Bob sends a tell message stating the available stock quantity.
  3. Alice sends a second ask-one message requesting the number of HDMI ports on the televisions.
  4. Bob sends a second tell message providing the HDMI port count.

As the activity does not supply actual warehouse inventory records, the dialogue will use illustrative values to demonstrate the communication process. These values are treated as assumed facts within the example rather than verified inventory data. The design also assumes that Bob possesses the requested information and that messages are delivered successfully. Although this simplified approach does not implement error handling, conflicting knowledge or asynchronous communication, it provides a controlled demonstration of how agents can exchange structured knowledge. These assumptions and limitations will be examined further in the analysis and evaluation section.

Agent Dialogue

The dialogue demonstrates a structured information exchange between Alice, the procurement agent, and Bob, the warehouse inventory agent. Knowledge Query and Manipulation Language (KQML) defines the communicative purpose of each message, while Knowledge Interchange Format (KIF) represents the information being requested and supplied. Alice initiates two queries concerning the stock availability and HDMI specifications of 50-inch televisions, with Bob responding to each request. The example assumes that the warehouse contains 12 televisions, each equipped with three HDMI ports. These figures are illustrative rather than verified inventory records. Both agents are assumed to share a common warehouse inventory ontology and interpret the product identifier consistently.

Message 1: Stock Query
(
ask-one
    :sender Alice
    :receiver Bob
    :language KIF
    :ontology warehouse-inventory
    :reply-with stock-query-001
    :content (stock-quantity television-50-inch ?quantity)
)

Alice initiates the dialogue by sending an ask-one message requesting the quantity of 50-inch televisions currently available in the warehouse. The KQML parameters identify the sender, receiver, content language and shared ontology, while the ask-one performative indicates that a single answer is required. The embedded KIF expression uses the predicate stock-quantity to relate the television category to the variable ?quantity, which represents the unknown stock level. The reply-with parameter assigns the identifier stock-query-001 so that Bob can associate his response with the original request.

Message 2: Stock Response
(
tell
    :sender Bob
    :receiver Alice
    :language KIF
    :ontology warehouse-inventory
    :in-reply-to stock-query-001
    :content (stock-quantity television-50-inch 12)
)

Bob responds using the tell performative to communicate a fact from the assumed warehouse inventory. The KIF expression (stock-quantity television-50-inch 12) states that 12 units of the specified television category are available. Unlike Alice's query, which contains an unbound variable, Bob's response provides a ground fact containing a specific numerical value. The in-reply-to parameter references stock-query-001, establishing the relationship between the query and its response. This demonstrates how KQML supports message correlation while KIF provides a formal representation of the inventory information.

Message 3: HDMI Query
(
ask-one
    :sender Alice
    :receiver Bob
    :language KIF
    :ontology warehouse-inventory
    :reply-with hdmi-query-002
    :content (hdmi-port-count television-50-inch ?ports)
)

Following the stock enquiry, Alice submits a second ask-one message requesting the number of HDMI ports available on the 50-inch televisions. The embedded KIF expression uses the predicate hdmi-port-count to associate the television category with the variable ?ports, representing the unknown number of HDMI ports per television. The product identifier television-50-inch is retained to maintain consistency with the earlier stock query. The message is assigned the identifier hdmi-query-002, allowing Bob to distinguish this request from the previous inventory enquiry. The example assumes that all televisions within the represented category have the same HDMI specification.

Message 4: HDMI Response
(
tell
    :sender Bob
    :receiver Alice
    :language KIF
    :ontology warehouse-inventory
    :in-reply-to hdmi-query-002
    :content (hdmi-port-count television-50-inch 3)
)

Bob completes the dialogue by sending a tell message containing the KIF expression (hdmi-port-count television-50-inch 3), which states that each television in the assumed product category has three HDMI ports. The in-reply-to parameter references hdmi-query-002, linking the response to Alice's second request. The result provides Alice with the product specification required alongside the previously supplied stock quantity. Together, the four messages demonstrate a consistent request-response communication pattern in which KQML specifies the interaction between agents and KIF represents the knowledge exchanged. The dialogue assumes successful message delivery and a shared interpretation of inventory predicates, while more complex conditions such as unavailable information, inconsistent product specifications and communication failures remain outside the scope of this simplified example.

Analysis & Evaluation

The dialogue demonstrates how KQML and KIF facilitate structured communication between autonomous agents. KQML distinguishes the intention of each message from its content, enabling Alice to request information without accessing Bob's internal inventory records. Finin et al. (1994) establish the importance of KQML performatives in supporting knowledge exchange between agents. The use of ask-one and tell is appropriate for the two information requests, while message identifiers maintain clear associations between queries and responses. However, the interaction remains a conceptual demonstration rather than a tested communication system.

KIF supports the representation of inventory information through predicates, variables and logical facts. Alice's queries specify unknown values, while Bob's responses provide corresponding stock quantities and product specifications. This structure promotes consistency but depends on both agents sharing the same interpretation of the inventory ontology. Singh (1998) highlights the limitations of communication approaches that do not adequately address interoperability between independently developed agents. Consequently, consistent message syntax alone cannot guarantee that agents interpret exchanged information correctly.

The dialogue also introduces several practical limitations.

  • The stock quantity is illustrative and does not account for real-time inventory changes, reservations or outdated records.
  • The generic television identifier assumes that all 50-inch televisions share identical HDMI specifications, despite possible differences between models.
  • The interaction assumes successful communication and does not address missing information, malformed messages or unsuccessful requests.
  • The sequential exchange does not demonstrate more complex behaviours such as negotiation, concurrent communication or coordination involving additional agents.

Labrou, Finin and Peng (1999) identify practical challenges in agent communication, including authentication, registration and supporting communication services. These considerations are absent from the simplified dialogue but would become important in an operational warehouse system. Improvements could include unique product identifiers, timestamped stock records, message validation and explicit handling of unsuccessful requests. Such extensions would improve accuracy and reliability without changing the underlying communication principles.

Overall, the dialogue successfully illustrates the fundamental roles of KQML and KIF in agent-based information exchange. Its strengths include clear agent responsibilities, appropriate performatives and consistent knowledge representation. Nevertheless, reliable implementation would require stronger semantic interoperability, more accurate inventory modelling and mechanisms for managing communication failures. The activity therefore demonstrates the foundations of intelligent agent communication while highlighting the distinction between a valid conceptual dialogue and a dependable multi-agent system.

Reflection

Developing the dialogue between Alice and Bob provided an opportunity to examine how intelligent agents communicate and exchange knowledge within a multi-agent environment. The activity clarified the distinction between KQML, which defines communication intentions, and KIF, which represents the information exchanged. Selecting the ask-one and tell performatives demonstrated how structured communication supports cooperation between agents with different responsibilities. Finin et al. (1994) establish the importance of agent communication languages in facilitating knowledge exchange, reinforcing the relevance of these concepts to practical agent-based computing.

One of the main challenges was ensuring consistency between the queries and their corresponding responses. Constructing the KIF predicates highlighted the importance of shared terminology, particularly when representing product categories and technical specifications. The assumption that all 50-inch televisions possess identical HDMI specifications illustrated how ambiguous knowledge representations could undermine communication accuracy. Singh (1998) examines interoperability challenges in agent communication, reinforcing the understanding that syntactically correct messages do not necessarily guarantee consistent interpretation between autonomous agents.

The activity also highlighted the limitations of simplified agent interactions. Although the four-message dialogue demonstrates a coherent information exchange, it assumes accurate inventory records, successful message delivery and shared knowledge between agents. Labrou, Finin and Peng (1999) identify broader implementation challenges associated with agent communication languages, emphasising the importance of supporting mechanisms for reliable interoperability. This helped distinguish the conceptual design of an agent dialogue from the additional requirements of an operational multi-agent system.

Overall, the activity strengthened my understanding of agent-based computing, communication protocols and formal knowledge representation. It demonstrated that effective collaboration between intelligent agents depends not only on appropriate message structures but also on consistent semantics and reliable information. Future improvements could include unique product identifiers, real-time inventory validation and explicit error handling to support more dependable communication in practical warehouse environments.
