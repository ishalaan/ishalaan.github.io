Activity Brief

This activity explores the evaluation of machine-learning model performance through practical experimentation in Jupyter Notebook. It involves running the model_Performance_Measurement.ipynb tutorial, examining classification and regression evaluation metrics, and changing different parameters to observe their effects on the Area Under the Curve (AUC) and the coefficient of determination (R²). The activity demonstrates how model settings and predictions influence performance measurements and their interpretation.

The notebook's classification metrics, ROC and AUC analysis, regression metrics, parameter experiments and observations are documented in this section of the e-Portfolio, followed by a reflection on the findings and the importance of reliable model evaluation.

The activity addresses the following learning outcomes.

  • Articulate the legal, social, ethical and professional issues faced by machine learning professionals.
Classification Metrics

The classification examples use several distinct sets of labels. Their scores describe separate calculations rather than one combined model assessment. In a binary confusion matrix, rows represent actual classes and columns predicted classes. With class 1 treated as positive, the four-record example gives TN = 0, FP = 2, FN = 1, TP = 1.

Reference example Metric Result
Six multiclass records Macro F1 0.266667
Six multiclass records Micro F1 0.333333
Six multiclass records Weighted F1 0.266667
Six multiclass records Macro precision 0.222222
Six multiclass records Macro recall 0.333333
Four-record accuracy example Accuracy 0.500000
Four ham/spam probability predictions Log loss 0.216162

Accuracy is the fraction of correct labels. Precision measures the fraction of predicted positives that are positive; recall measures the fraction of actual positives detected. F1 is the harmonic mean of precision and recall. Macro averages give each class equal weight, weighted averages use class support, and micro averages pool decisions. Macro and weighted F1 coincide here because all three classes have two records, not because the averaging methods are interchangeable.

The separate synthetic-data SVC uses 75 training and 25 test records. Its confusion matrix is [[12, 1], [2, 10]], giving 22/25 correct predictions (88% accuracy). The notebook also reproduces the classification report and multilabel F1 example. In the all-zero binary case, zero_division=1 assigns one to an otherwise undefined positive-class F1; this does not demonstrate an ability to detect positives.

Log loss assesses probabilities, with lower values preferred. The ham/spam example uses columns ordered as ham then spam and produces 0.216162. Unlike accuracy, log loss distinguishes confident and uncertain predictions, and strongly penalises confident errors.

ROC & AUC

A receiver operating characteristic (ROC) curve plots true-positive rate, TP/(TP + FN), against false-positive rate, FP/(FP + TN), as a score threshold changes. Binary AUC measures the probability that a randomly selected positive receives a higher score than a randomly selected negative, counting ties as one-half. An AUC of 0.5 indicates chance-level ranking, while one indicates perfect ranking on the evaluated records (Fawcett, 2006).

Reference calculation Evaluation data AUC
Breast-cancer logistic regression Same 569 records used for fitting 0.994741
Iris logistic regression, macro OvR Same 150 records used for fitting 0.991333
Noisy Iris SVC: setosa versus rest 75 held-out records 0.912698
Noisy Iris SVC: versicolor versus rest 75 held-out records 0.603704
Noisy Iris SVC: virginica versus rest 75 held-out records 0.786765
Noisy Iris SVC: macro average 75 held-out records 0.767722
Noisy Iris SVC: micro average 75 held-out records 0.727733

The two logistic results are resubstitution scores and should not be presented as evidence of performance on unseen data. In the breast-cancer dataset, label 1 is benign, so the original probability column evaluates benign as the positive class. A clinically meaningful assessment would need an explicitly chosen target and evaluation protocol; this example establishes neither.

The Iris SVC adds 800 Gaussian noise features to the original four measurements, then uses the reference 50:50 split. One-versus-rest (OvR) treats each class as positive against the other two. Macro AUC averages the three class AUCs; micro AUC pools all class–record scores and can depend on how score scales compare across classifiers. The executed notebook plots all three ROC curves. AUC measures discrimination, not probability calibration or the consequences of a particular operating threshold.

Regression Metrics

The regression reference compares y = [3, −0.5, 2, 7] with ŷ = [2.5, 0, 2, 8]. These are fixed numerical examples, not predictions from a fitted regression model. The source heading "RMSE" is corrected: mean_squared_error returns MSE, whose square root gives RMSE.

Metric Definition Reference value
MSE Mean squared residual 0.375000
RMSE Square root of MSE 0.612372
MAE Mean absolute residual 0.500000
R² 1 − SSE/SST 0.948608

MSE gives greater weight to large residuals and has squared target units. RMSE and MAE have the same units as the target, making the magnitude of error easier to interpret. Here SSE = 1.5 and SST = Σ(y − mean(y))² = 29.1875, giving R² = 1 − 1.5/29.1875 = 0.948608.

R² is a goodness-of-fit score, not an error to minimise. One denotes a perfect fit; zero matches the constant predictor equal to the evaluated targets' mean; a negative value means greater squared error than that comparator. In this example, R² represents a 94.86% reduction in squared error relative to that mean. It does not establish causality or out-of-sample explanatory power. Constant targets have zero SST, so the ordinary formula is undefined and software conventions require care.

AUC Experiments

The AUC comparisons preserve the same 75 training and 75 evaluation records, using split seed 0. The first experiment holds the linear OvR SVC at C = 1 and changes only the number of irrelevant features. Noise is generated once using seed 0; each smaller feature set takes a prefix of the same 800-column matrix. No standardisation is introduced into this Iris comparison.

Added noise features Setosa AUC Versicolor AUC Virginica AUC Macro AUC
0 1.000000 0.721481 0.995098 0.905527
20 1.000000 0.660741 0.906046 0.855595
200 0.998236 0.637778 0.829248 0.821754
800 0.912698 0.603704 0.786765 0.767722

Macro AUC falls from 0.905527 without added noise to 0.767722 with 800 irrelevant features. Versicolor remains the weakest one-versus-rest result. This controlled comparison shows reduced ranking performance for this particular noise draw and split; it does not imply that every additional feature or every dataset will behave similarly.

Smaller C applies stronger regularisation. Macro AUC rises from 0.752955 at C = 0.001 to 0.767722 at C = 0.01, then remains unchanged through C = 10. Increasing C therefore provides no further ranking improvement in these runs. This separate comparison fits one standardised logistic model to a stratified 70% breast-cancer training split and evaluates the remaining 30%, using seed 0. Scaling is fitted only on training data. Raising the threshold reduces benign recall and increases benign precision in this run, while score AUC remains 0.995619. The probability ranking is unchanged: only the label decisions differ. These illustrative thresholds are not clinical recommendations.

Repeated comparison against the same held-out records makes them exploratory validation data. Selecting a configuration from these tables would require independent final testing. Repeated splits or cross-validation would also help quantify variability; neither is supplied by a single reported score.

R² Experiments

The residual experiment keeps the four observed targets fixed and sets ŷ(k) = y + k(ŷ(reference) − y). Only the residual multiplier changes. This isolates how error magnitude affects the metrics without introducing changes in training or data splitting.

Residual multiplier k MSE RMSE MAE R²
0 0.000000 0.000000 0.000000 1.000000
0.5 0.093750 0.306186 0.250000 0.987152
1 0.375000 0.612372 0.500000 0.948608
2 1.500000 1.224745 1.000000 0.794433
4 6.000000 2.449490 2.000000 0.177730
8 24.000000 4.898979 4.000000 -2.289079

Halving the residuals raises R² from 0.948608 to 0.987152. Doubling them quadruples MSE and reduces R² to 0.794433. At eight times the reference residuals, R² becomes −2.289079, meaning the squared error exceeds that of the observed-mean predictor. The relationship is exact for these fixed targets: R²(k) = 1 − k² × 1.5/29.1875.

Additional Controls
Scenario MSE RMSE MAE R²
Observed-mean predictor 7.296875 2.701273 2.125000 0.000000
Reference predictions + 2 5.375000 2.318405 2.250000 0.263383
Both arrays multiplied by 10 37.500000 6.123724 5.000000 0.948608

Predicting the observed mean gives R² = 0 by construction. Adding two to every reference prediction reduces R² to 0.263383, showing that systematic bias matters even when relative ordering is retained. Multiplying both targets and predictions by ten leaves R² unchanged but multiplies MAE and RMSE by ten and MSE by one hundred. Absolute error therefore needs a stated unit; R² needs the context of target variability. These four-point examples demonstrate metric behaviour rather than model generalisation.

Reflection

The experiments show why an evaluation needs more than a headline score. Additional noise reduced Iris macro AUC, but increasing C beyond 0.01 produced no improvement. Changing the binary threshold altered decisions while leaving AUC unchanged, reinforcing the distinction between ranking and an operating policy (Fawcett, 2006). For rare positive outcomes, precision–recall analysis would provide an important additional view (Saito and Rehmsmeier, 2015).

The regression results also depend on the comparison being made. R² supplies a variance-relative baseline (Chicco, Warrens and Jurman, 2021), while MAE and RMSE retain the scale of the errors. The negative-R² and unit-rescaling controls make that distinction explicit. A stronger evaluation would reserve independent final data, report variability and examine errors across relevant groups. Legal questions include permitted data use, privacy and discriminatory outcomes. Professional responsibility includes explaining which class is positive, protecting sensitive data and considering who bears the cost of mistakes; a high aggregate score alone cannot establish fairness or justify deployment.
