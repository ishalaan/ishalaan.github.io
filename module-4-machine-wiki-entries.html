Activity Brief

This activity explores covariance, Pearson correlation and three regression techniques through practical experimentation in Jupyter Notebook. It involves running four provided Python programmes, modifying variables and observing how changes in data points affect the strength and direction of correlations and the behaviour of regression models. The activity demonstrates how statistical relationships and predictive models respond to different datasets and variable configurations.

The completed experiments, visualisations and observations for covariance and Pearson correlation, linear regression, multiple linear regression and polynomial regression are documented in this section of the e-Portfolio, alongside a reflection on the findings and limitations of the techniques.

The activity addresses the following learning outcomes.

  • Articulate the legal, social, ethical and professional issues faced by machine learning professionals.
  • Understand the applicability and challenges associated with different datasets for the use of machine learning algorithms.
Covariance & Pearson Correlation

This section will document the experiments conducted using covariance_pearson_correlation.ipynb. It will present the original results and the effects of modifying data points on covariance and Pearson correlation, supported by relevant visualisations and explanations of the observed relationships.

Linear Regression

This section will document the experiments conducted using linear_regression.ipynb. It will present the original regression results, modifications to the dataset and the resulting changes in the fitted regression line, supported by visualisations and observations about the relationship between the variables.

Multiple Linear Regression

This section will document the experiments conducted using multiple_linear_regression.ipynb. It will examine how changes to multiple independent variables and their data points influence the regression model, presenting relevant results, comparisons and observations about the contribution of different predictors.

Polynomial Regression

This section will document the experiments conducted using polynomial_regression.ipynb. It will present the fitted polynomial models and investigate how changes in data points or model configuration affect the regression curve, supported by visualisations and observations about modelling nonlinear relationships.

Reflection

This section will critically reflect on the findings from the four experiments, comparing how covariance, correlation and different regression techniques respond to changes in data. It will consider the strengths, assumptions and limitations of each technique, the challenges encountered during experimentation and the importance of selecting appropriate datasets and models for reliable machine-learning analysis.
